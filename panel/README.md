# GATEOMETRY PANEL

!Untested!

The **Gateometry** front panel provides a compact (for a given value of compact), intuitive interface for the eight-channel **Euclidean** rhythm generator. It features an OLED display for pattern visualization and menu navigation, a rotary encoder with an integrated pushbutton for parameter selection and editing, and dedicated run/stop and mute controls with LED status indication. Eight individual gate output jacks provide connections to external **Eurorack** modules, while clock input, clock output, and reset connections allow integration with other sequencers and clock sources. The panel is designed to provide convenient access to **Gateometry**'s rhythmic capabilities while maintaining a clean, functional **Eurorack** layout.
